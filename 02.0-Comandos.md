# 00. Introducción y comandos básicos

Git es una herramienta totalmente diseñada para su uso desde terminal, por lo que en este curso trabajaremos bastante con esta tanto desde powershell cómo desde git bash.

Actualmente los comandos básicos de Poweshell y de linux se parecen bastante, aquí tenemos una lista de los comandos que vamos a usar:

🐧🪟
## Comandos de terminal
- `cd` 🐧🪟: Cambiar de directorio.
- `ls` 🐧🪟: Ver contenido de un directorio.
- `cat` 🐧🪟: Ver contenido de un archivo de texto plano.
- `code` 🐧🪟: Abrir o crear un archivo con Visual Studio Code.
