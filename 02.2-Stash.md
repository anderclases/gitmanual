✅ Son solo locales (viven en tu máquina)
❌ No forman parte del historial de commits
❌ No se suben con git push

git stash
 te permite guardar temporalmente cambios no confirmados (no commit) para limpiar tu entorno de trabajo sin perder lo que estabas haciendo.

Guardar cambios en stash: 
git stash

Guardar con mensaje

git stash push -m "trabajo en login"

Ver stashes guardados
git stash list

Recuperar el último stash (sin borrarlo)

git stash apply

Recuperar y eliminarlo de la lista
git stash pop

Aplicar uno específico
git stash apply stash@{1}

Eliminar un stash
git stash drop stash@{0}

Borrar todos los stashes
git stash clear

Estás trabajando en una feature, pero necesitas cambiar urgente a otra rama:

git stash
git checkout otra-rama

Luego vuelves:

git checkout mi-rama
git stash pop
