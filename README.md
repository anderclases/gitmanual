# Introducción a github
En este curso aprenderemos los fundamentos de git y github.

Para ello es importante compreder la diferencia entre ambos. Git gestiona versiones de código, GitHub las guarda y facilita el trabajo en equipo.

Git → Es una herramienta local. 
GitHub → Es una plataforma online que usa Git.
